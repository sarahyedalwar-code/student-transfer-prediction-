# Student Transfer Prediction

## Project Overview

This project explores factors associated with community college student transfer outcomes using Python, statistical analysis, and machine learning. The goal is to examine how academic performance, completed college units, study hours, and tutoring participation relate to transfer success.

The project uses a dataset of 1,200 simulated student records to demonstrate data science techniques.

## Tools & Technologies

- Python
- NumPy
- pandas
- Matplotlib
- scikit-learn
- Jupyter Notebook

## Project Methods

- **Data Analysis:** Examined GPA, completed units, study hours, and tutoring participation.
- **Probability & Sampling:** Calculated transfer proportions and explored sampling variability using 1,000 random samples.
- **Hypothesis Testing:** Conducted a permutation test to investigate the relationship between tutoring participation and transfer outcomes.
- **Machine Learning:** Trained a logistic regression model to predict transfer outcomes based on student characteristics.

## Key Findings

- Students who transferred had an average GPA of 3.22 compared with 2.78 for those who did not.
- Students who transferred completed approximately 11 more college units on average.
- Students who participated in tutoring had an 11.53-percentage-point higher transfer rate.
- The logistic regression model achieved **75.42% accuracy** on the synthetic test dataset.


## Project Development

This project was developed as an independent learning exercise applying concepts from introductory Data Science coursework. AI was used to support code development and debugging.
